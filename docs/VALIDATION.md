# 发布检查

2026-11-05 的公开副本验证：

- macOS 独立构建完成，使用 Apple Silicon / Swift；414 项原生检查通过，其中包含合成图片的真实 Vision OCR。
- 门户脚本的 24 项登录表单、141 项设备入口隔离检查通过，不使用真实账号、网页或网络。
- 浏览器扩展合成检查：44 个场景、414 项断言通过。
- Python Paddle 输入清理检查：2 项通过。
- 所有测试使用合成数据；本轮没有真实发送手机通知或对生产门户执行测试。

Windows/Android 源码经过定向迁移和静态检查。本轮未在 Windows 环境完成构建，也未完成 Android SDK 构建或手机端到端验证，不能用 macOS 或 JavaScript 结果替代。

`python3 scripts/check_public_release.py` 检查 Git 跟踪清单、禁止目录、超大文件、私人路径和常见凭据模式；它不替代人工审核或构成“没有所有秘密”的保证。

当前仍有远程重连空白页及恢复较慢的已知问题，见主 README。

## 1.4.0 三端下载

- Mac 主程序与配对工具均构建为 Intel 和 Apple 芯片通用 App，主程序进行 424 项离线检查，包含 Vision 识别合成样本。网页入口的 165 项隔离检查使用合成页面。打包脚本在 ZIP 解压之后重新验证应用签名。
- Windows 在 GitHub 的 Windows 环境编译桌面程序，并从生成的 ZIP 解压、打开真实主窗口两次，检查用户配置保留。合成邮件测试覆盖未读蓝点、邮件身份、分页连接、正文终点、整批排队和发送结果不明确时保留待核对。
- 安卓 APK 的签名和包名与先前 1.1 版匹配，包内有效载荷会与公开源码重新构建的产物逐项比较。与 Mac 的 TLS 配对测试覆盖错误码、前导零、过期、重复使用、证书固定及访问控制。1.1 的局域网六位码配对已有人用实机确认，1.4.0 的签名 APK 已在 Android 15 模拟器实际安装，核验了浅色、深色配对页面和输入框。真实邮箱到手机推送仍需使用者在自己的环境验收。
