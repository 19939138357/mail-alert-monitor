# 本地数据与通知

OCR 在本机进行。运行时为恢复任务和去重，会持久保存邮件元数据、已读取正文及发送结果；文件保存在使用者自己的设备上。设置文件和本机日志不应当作可公开资料。

配置推送后，邮件主题、时间和正文会提交给所配置的通知服务。先确认自己有权向该服务转发这些邮件。旧版独立响铃助手启用通知监听时可以读取系统通知。下载页上的安卓「监控机 1」是局域网控制端，清单只申请网络访问权限。

公开版与原本机安装版使用不同 macOS bundle 和 Keychain service 标识。没有迁移任何账号、Token、原队列、浏览器 profile 或签名材料。示例门户和邮件地址均为合成值，历史样本由源码本地生成。

本仓库的 `.gitignore` 只是补充保护。发布或提交前仍须逐项检查文件清单；运行记录、个人截图、邮件样本、配置密文与私钥也不能上传。

手机配对在选中的本地地址提供 HTTPS 服务。连接凭据只保存在已配对设备上。安卓可以读取近期邮件主题与状态，用户在 Mac 允许共享对应邮箱页面后，还可在手机上查看和操作该页面。公开安装包与示例截图均不含已配对设备的凭据或真实邮件。
