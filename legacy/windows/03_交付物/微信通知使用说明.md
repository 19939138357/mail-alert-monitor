# 本机通知配置

在 Windows 根脚本目录运行 `Configure-PhoneNotification.ps1`，填写自己的 PushPlus、QQ 邮箱或钉钉配置并保存。凭据由当前 Windows 用户加密保存，不需要写进源码或公开示例配置。

先运行 `Test-VerificationPhone.ps1` 发送测试，核对手机通知与正文。服务返回受理成功不代表手机已经收到。夜间响铃另需构建和安装仓库 `android-alarm/` 中的助手，并由使用者在手机授权通知访问和开启守护。

不要提交 `monitor_config.json`、自动生成的 `04_资料/私密配置/`、浏览器登录资料或任何运行日志、截图和邮件正文。
