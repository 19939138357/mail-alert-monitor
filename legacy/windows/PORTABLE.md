邮件监控 · Windows 便携版

首次使用
1. 在 Windows 10/11 上把 ZIP 全部解压到自己的可写文件夹，双击 MailAlertMonitor.exe。
2. 打开要监控的邮箱。点击「监控设置」，指定窗口标题中的文字、提醒关键词和扫描间隔。默认匹配 Foxmail 窗口或同名进程。通过浏览器查看远程桌面时，请填远程页面独有的窗口标题，并清空进程名，以便只匹配该窗口。
3. 在「通知设置」选择微信 PushPlus、QQ 邮箱或钉钉，填入自己的接收配置。「发送测试通知」会实际发送一次，请核对手机收件。
4. 点「启动监控」。让邮箱画面可见，防止 Windows 锁屏或休眠。请通过「停止监控」结束后台扫描。

转发 Foxmail 未读邮件的正文
在「监控设置」选择「Foxmail 未读邮件正文」，填写邮箱窗口的独有标题。把 Foxmail 设为中间邮件列表、右侧阅读窗，并展开含发件人、时间、大小的邮件头。点「框选邮箱区域」：先拖框选中未读圆点、发件人、主题和时间，再拖框选中右侧邮件头和正文，点「保存」。配置手机渠道后启动监控，将邮箱保持在前台。
从屏幕上已可见的未读邮件开始，程序逐封核对主题与正文，打开后由 Foxmail 标为已读。确认正文结尾后再推送，无法核对时可看「待核对邮件」。无法读取列表外的邮件、附件或图片内容。识别和实际手机送达依赖现场条件。发送结果不明时请先核对手机，程序不会自动重复发送。

判断正文末尾时，本机 Foxmail 需要能读取完整的系统文字范围。浏览器远程画面请把右侧经典滚动条的上下箭头、滑块也框进阅读区。远程短邮件没有可识别的滚动条时，即使画面底下有空白，也会进入待核对。

Windows 功能
默认使用电脑的 Windows OCR 识别新出现的关键词，启动时已存在的内容作为基线。识别语言为中文，请在 Windows 语言设置中安装中文光学字符识别。首次运行自动生成 monitor_config.json，之后保留你的设置。高级用户可按开源仓库的 Windows 说明校准两类抽查邮件的开信和确认码规则。
日志在软件文件夹的 monitor.log，通知凭据由当前 Windows 用户加密。请勿共享已使用的软件文件夹。更新版本请解压到新目录，停止旧版后再迁移自己的配置。此程序需要 Windows PowerShell 5.1、.NET Framework 4.8 和系统 OCR。
安卓「监控机 1」的六位码遥控目前配对 Mac。Windows 可将识别提醒发送到配置好的手机渠道。
