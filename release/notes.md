Mac 和 Windows 新增小米 MiMo 本地正文识别，模型在自己的电脑运行。

- 首次从设置点「安装或启动小米模型」，下载并校验约 5.4 GB 的 MiMo-VL-7B-RL-2508 量化权重。建议至少 16 GB 内存。Mac 的安装工具需要 Python 3.8+，Windows 使用随包的安装工具。
- 在「正文识别」选择「小米 MiMo 本地 · 免费」。开始监控时会启动本地模型工具，等待就绪后处理邮件。正文由小米抄录，系统负责未读定位、鼠标点位和末尾验证。
- 模型未就绪时保留未读队列，识别过程中正文画面变化时重新核对。新邮件仍参与排队，长时间识别的当前邮件保留自己的读取进度。
- 本机连接凭据自动生成。安装包包含程序和安装工具，模型在第一次启动时下载。

| 文件 | 平台 |
| --- | --- |
| MailAlertMonitor-macOS.zip | macOS 14+，Apple 芯片和 Intel |
| MailAlertMonitor-Windows.zip | Windows 10/11 x64，.NET Framework 4.8 |
| MailAlertMonitor-Android.apk | 安卓 8+ 的遥控端，沿用已发布的 1.4.0 包与签名 |

16 GB Apple 芯片 Mac 的中文合成告警约 24 秒，主题、确认码、设备地址、文件名、状态与最后一段等 8 项核对通过。Windows 本地连接通过原生检查，实际推理速度取决于电脑配置。

Mac 使用本地签名。下载后完整解压，按包内使用说明配置自己的邮箱窗口与通知渠道。三个文件的校验值见 SHA256SUMS.txt。
