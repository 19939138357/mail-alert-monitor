邮件监控 · macOS 1.4.1
适用于 Intel 或 Apple 芯片的 Mac，系统版本 macOS 14 或更高。

首次使用
将「抽查邮件监控开源版.app」和「手机配对.app」一起复制到同一文件夹，例如「应用程序」。打开「抽查邮件监控开源版」。GitHub 下载的软件包使用本地签名，未做 Apple 公证。可在确认来源后按 macOS 的提示允许打开。

1. 在 Safari 打开 HTTPS 远程 Foxmail 收件箱，并保持选中邮箱标签。将邮件按「是否已读」排序，收起已读组。
2. 在「通知与设置」根据需要开启屏幕录制和辅助功能。系统要求时，退出并重新打开本程序。
3. 点「选择邮箱窗口」，挑选刚打开的窗口并点「预览识别」。打开「识别区域」，框选未读小蓝点及邮件列表，再框选邮件头和正文。如果想先了解识别效果，可直接查看内置的合成示例截图。
4. 在「通知与设置」填入自己的 PushPlus Token，保存后可点「测试微信」核验收件。请自行确认有权将该邮箱的内容通过所配置的服务推送。
5. 回到「监控总览」，点「开始监控」。首次启动时，核对窗口标题和网站，允许监控这个页面。以后遇到新的会话地址时，需要在 Mac 上再次确认。新发现的未读邮件按原主题列在「最近邮件」。服务受理后，可在手机核对送达。结果不确定时在「运行记录」查看并核对。

安卓控制
手机与电脑接入同一可信 Wi-Fi。在 Mac 的侧栏点「手机配对」，选择局域网地址并显示六位配对码。在安卓「监控机 1」内输入该码。使用配对码之前，先确认两端的网络相通。手机配对工具负责连接，主程序负责扫描。安装包中的两个 App 要放在同一文件夹。
配对工具需要 Python 3.8 或更高版本，主监控可独立启动。如果配对工具提示缺少 Python 3，请按配对窗口的提示安装对应运行环境。

本机存储和环境
队列、设置及运行状态位于「资源库/Application Support/MailAlertMonitorOpenSource」。推送凭据由 macOS 钥匙串保存。公开版首次使用需单独选择窗口和配置通道。公开下载的默认入口用于监控已打开的 Foxmail 窗口。特定单位的门户登录和重连需要适配其网页结构，源码说明在 docs/PORTAL_ADAPTER.md。

小米本地正文识别
在「通知与设置」选择「小米 MiMo 本地 · 免费」，点「安装或启动小米模型」。首次下载约 5.4 GB，等待终端显示就绪后可点「测试小米识别」。模型工具需要 Python 3.8+。保留终端窗口运行，按 Control+C 可以结束模型程序。旧设置升级后可手动切换引擎。
