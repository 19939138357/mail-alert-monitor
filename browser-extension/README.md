# 邮件告警浏览器扩展

Manifest V3 扩展，可在用户主动开启的普通 DOM 邮箱页面识别新的关键词内容，通过 Windows 本机接收端通知手机。它不能读取远程桌面画布中的 Foxmail。

1. 在 `legacy/windows/` 配置通知并运行 `Configure-BrowserAlert.ps1`。
2. 在 Edge/Chrome 的扩展管理页面选择“加载解压缩的扩展”，选本目录。
3. 将本机接收端生成的配对码填入扩展，连接后在目标邮箱页面点“开启当前页”。

扩展请求 `activeTab`、脚本注入、存储、闹钟以及 `http://127.0.0.1:17368/*` 的接收端访问权限。页面刷新或导航后需要重新开启。首次已有内容作为基线，不直接补发历史；通知预览和 DOM 变化可能影响识别。

配对码存在浏览器本地存储，临时监控队列存在会话存储。源码没有预置配对码。请先用自己的合成内容与测试通知验收，再用于实际邮箱。
