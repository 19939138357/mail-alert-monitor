# 小米 MiMo 本地正文识别

模型在自己的电脑上运行，使用小米 MiMo-VL-7B-RL-2508。初次安装下载约 5.4 GB 模型文件和对应平台的 llama.cpp 程序，随后可以离线识别。运行建议至少 16 GB 内存，CPU 识别所需时间受电脑性能影响。选择小米引擎后，「开始监控」会按需打开本地模型工具。

## Mac

在监控程序「通知与设置」选择「小米 MiMo 本地 · 免费」，点「安装或启动小米模型」。安装工具需要 Python 3.8 或更高版本。首次下载完成后，等待终端显示「小米模型已就绪」，再回到程序点「测试小米识别」。

模型保存在 `~/Library/Application Support/MailAlertMonitorOpenSource/mimo/`。保留模型窗口运行。需要释放模型内存时，在模型窗口按 Control+C。

## Windows

完整解压便携包，在「监控设置」选择「Foxmail 未读邮件正文」模式，并将「正文识别」设为「小米 MiMo 本地 · 免费」。点「安装或启动模型」，等待窗口显示就绪。Windows 使用 x64 CPU 程序，安装工具随包提供。

模型保存在软件文件夹内的 `MiMo/`。下载中断后重新打开同一工具即可继续。更新时保留自己的模型目录可以复用已校验的模型。

## 识别与邮件核对

小米模型负责正文文字抄录。系统 OCR 与像素检查继续提供未读标记、列表位置和滚动终点依据。模型处理期间画面变化会使本轮结果失效。模型未启动时先保留未读队列，等待模型就绪再打开邮件。返回被截断、格式异常或邮件身份不匹配时，原任务保留等待核对。

本地接口固定绑定 `127.0.0.1:48765`。安装工具自动生成本机连接凭据，程序从自己的数据目录读取。需要保管好运行后的模型目录，分享软件请使用原始发布 ZIP。

## 来源与校验

- 原始模型来自 [XiaomiMiMo/MiMo-VL](https://github.com/XiaomiMiMo/MiMo-VL)。
- 使用 [mradermacher 的 MiMo-VL-7B-RL-2508 社区量化](https://huggingface.co/mradermacher/MiMo-VL-7B-RL-2508-GGUF)，语言权重 Q4_K_M，配套视觉投影器 Q8_0。具体修订号、文件大小和 SHA-256 固定在 `model.json`。
- 运行程序来自 [ggml-org/llama.cpp](https://github.com/ggml-org/llama.cpp/releases/tag/b12180)，安装时校验官方发布资产的 SHA-256。
- 下载模型遇到网络故障时可从 HF Mirror 获取同一公开文件，完成后仍按固定的 SHA-256 校验。识别请求只发送到本机接口。
